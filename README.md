# 📝 Responsive Blog Website using Django

## 📌 Introduction

This project is a **responsive blog website** built using **Python Django**. It allows writers/admins to register, log in, and manage blog posts (create, update, delete). 
Visitors can view all published blog posts without logging in. The website is fully responsive for desktop, tablet, and mobile devices.


## 🚧 Features

- ✅ User Sign Up & Login using Email and Password  
- ✅ Admin/Writer can Create, Edit, and Delete Blog Posts  
- ✅ Each blog post has Title, Description, Publish Date, Author Name, Category, and Image  
- ✅ Visitors can view blogs without login  
- ✅ Responsive Design with Navigation Bar, Blog Sections, and Footer  
- ✅ Clicking on a blog shows the full post in a detailed view  


## ⚠️ Challenges Faced

- Setting up a **custom user model** to use email instead of username  
- Making the design **fully responsive** across all devices  
- Handling image uploads and media files in Django  
- Creating clean URLs with slugs for individual blog posts  
- Managing authentication and permissions for blog editing
